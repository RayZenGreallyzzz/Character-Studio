# Phoenix Character Studio — Android, прототип 0.1

Новый, **отдельный** проект редактора персонажей. Не изменяет Rig Animation Studio, Mocap Studio, Rig Weapon Studio, Anim Retarget, QDQR и World Builder.

## Что реализовано в исходниках

- Загрузка **готового GLB со скелетом** и его анимаций в 3D-просмотрщик.
- Добавление отдельной детали **GLB** (волосы, хвост, уши, маска/лицо, одежда) и привязка к выбранной **существующей** кости.
- Создание дополнительных цепочек костей для волос, хвоста, лица, ушей, крыльев, одежды; кнопка для **парных костей груди** (`Breast_L_01`, `Breast_R_01`).
- Перемещение, вращение и масштаб детали по XYZ; редактирование позиции и поворота кости.
- Перевод простых добавленных деталей из Mesh в SkinnedMesh; автораздача весов по близости к костям цепочки.
- **Экспериментальное** назначение весов новых костей на существующий SkinnedMesh тела (например, груди). Работает с ограничением GLB: максимум 4 веса на вершину.
- Проигрывание существующих анимаций, пользовательские клипы, запись угла выбранной новой кости ключевым кадром.
- Вторичное синусоидальное движение новых костей (покачивание). При экспорте оно пересчитывается в quaternion-keyframes с частотой 30 FPS. Это **не физический симулятор**.
- Экспорт собранной сцены персонажа с мешами, костями и анимациями в **GLB** через GLTFExporter.
- Проект **.pcs** сохраняет исходный GLB, GLB деталей, созданные кости, настройки и ключи, чтобы повторно редактировать их без изменения исходных файлов.
- Offline WebView: после установки APK интернет не нужен для работы редактора. Meshopt-поддержка в Three.js, Draco не подключен.

## Сборка APK через GitHub Actions (с Android-планшета)

1. Создайте **отдельный пустой репозиторий** `PhoenixCharacterStudio` на GitHub. Не кладите файлы в AnimRetargetAndroid или QDQR.
2. Загрузите в **корень** репозитория содержимое этого ZIP: `package.json`, `src/`, `.github/workflows/android-debug.yml` и остальные файлы. Папку `.github` обязательно сохранить (она может быть скрыта в некоторых архиваторах).
3. Откройте **Actions → Android APK → Run workflow** (либо сборка стартует автоматически после push в `main`).
4. После завершения загрузите **Artifacts → PhoenixCharacterStudio-debug-apk**, распакуйте и установите `app-debug.apk`.

Это **инструкция по сборке**, не подтверждение успешной сборки. В среде подготовки исходников не было доступа к npm и Android SDK, поэтому реальные `npm run build`, `gradle assembleDebug` и установка APK на устройство здесь не проверены. Запуск и проба на конкретных GLB необходимы.

## Первый запуск

1. Нажать **«Загрузить персонажа GLB»**, выбрать модель с костями. Если у модели нет костей, приложение выдаст предупреждение.
2. В «Скелет» выбрать `Head`, `UpperChest` или `Hips`, создать цепочку волос / груди / хвоста.
3. В «Детали» импортировать волосы или хвост как отдельный GLB; кнопкой «Прикрепить деталь к кости» привязать объект.
4. Для сгиба длинной детали — сначала расставить цепочку костей и позицию импортированной детали, затем «Привязать деталь к цепочке» (скелетная деформация экспериментальная). После этого двигать именно кости.
5. Для груди — «Пара костей груди L/R», вручную расположить кости внутри нужных областей и **по очереди** назначить веса каждой кости. Перед назначением выбрать исходную/нейтральную позу. Если результат плохой, заново загрузить исходный проект и изменить радиус/силу.
6. В разделе «Анимация» выбрать клип, время, нужную новую кость, задать поворот и нажать «Записать ключ кости»; включить вторичное движение по необходимости.
7. «Проект» сохраняет редактируемый `.pcs`. «Экспорт GLB» сохраняет итоговую анимируемую модель через Android Share либо обычную загрузку в браузере.

## Что пока НЕ готово (важно)

- **Нет готового проверенного APK** в этом ZIP; содержимое — исходный проект + workflow для его сборки.
- Нет FBX импорта/экспорта, нет VRM; поддерживается GLB. `.gltf` с отдельными `.bin`/текстурами не импортируется.
- Запекание означает **сборку и экспорт GLB с отдельными skinned meshes и анимациями**, а не обязательное слияние всей геометрии в единственный меш и не запекание нескольких материалов в атлас.
- Автовеса для тела — приближённые сферические; их необходимо проверять на пользовательских моделях. Нет кисти Weight Paint и нет undo.
- Нет полноценной физики волос/груди/хвоста и коллизий — только параметрическое покачивание, запекаемое в ключи. Сложное вторичное движение запланировано.
- Аксессуары с уже существующим ригом, сложными морфами или нестандартными материалами не проходят автоматический перескиннинг. Лицо пока добавляется как отдельный меш/текстура, **нет** переноса мимики между разными головами.
- Автоматического подгона формы под любую голову нет: для волос/деталей используются ручные XYZ.
- Нет универсальной гарантии для всех GLB: модели с разными координатными системами, custom bone-roll, нестандартными весами требуют тестирования.
- Новые кости не должны нарушать существующую Mixamo-иерархию, однако экспорт и ретаргетинг на целевой платформе (Godot) надо проверить на образце.

## Локальный запуск на ПК (не обязателен)

```bash
npm install
npm test
npm run dev
npm run build
npx cap add android
npx cap sync android
cd android && ./gradlew assembleDebug
```

## Архитектура

- `src/main.js` — Android-friendly UI, импорт/экспорт, сцена, проект и таймлайн.
- `src/rig.js` — кости, авто-веса, скиннинг дополнительных деталей, подготовка дорожек анимаций.
- `src/rig-utils.js` — чистые функции для веса/имён/ключей; `tests/rig-utils.test.js` — быстрые тесты.
- `.github/workflows/android-debug.yml` — GitHub Actions для сборки APK.

Работает без серверной части и без загрузки персонажей куда-либо; файлы обрабатываются локально на устройстве.
